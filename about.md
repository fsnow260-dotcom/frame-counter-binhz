# NaNDL Precision Suite

A sub-frame CBF analytics mod for Geometry Dash 2.2081, featuring:

- **CBF Input Interception**: Sub-frame input tracking at 240 TPS
- **NaNDL σ/s Solver**: Real-time precision metrics with K_T, K_U, K_C modifiers
- **Multi-format Replay Parser**: Support for .gdr, .slc, .json, .fwc
- **Clean HUD Overlay**: Live σ/s readout with tight-window indicators
- **Solver Settings Popup**: Configurable target probability and modifiers
- **Pause Menu Button**: Quick access from the pause screen
- **Audio Cues**: Customizable sound triggers for tight tolerances
- **Export Utility**: JSON and .fwc report generation
